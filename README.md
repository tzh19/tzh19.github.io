# Thinzar's portfolio

A one-page responsive portfolio made with HTML and CSS. No build or installation required.

## Start here

Open `index.html` in your browser. Edit text in `index.html` and appearance in `styles.css`, then refresh the browser.

Google Fonts is optional: if offline, the site uses local fallback fonts.

## Before publishing

- Review your name, professional description, and project details.
- Add the email or social links you want visitors to use. No contact details have been guessed.
- Add a public rental API repository link when ready.
- Check the page on your phone and desktop.
- Only include work information you are allowed to share.

## Publish on GitHub Pages

1. Create a public repository named YOUR-USERNAME.github.io, replacing YOUR-USERNAME with your GitHub username.
2. Commit the contents of this folder to the repository root (index.html must be at the root).
3. In the repository, open Settings → Pages.
4. Choose Deploy from a branch, select main and / (root), and save.
5. Wait for the deployment to complete, then visit https://YOUR-USERNAME.github.io.

Make a small edit, commit and push it, then check the deployment and live page. Practice reverting that commit to learn recovery.

## What each file does

- index.html: content, links, and page structure.
- styles.css: colors, spacing, typography, and mobile layouts.
- README.md: learning and deployment notes; not displayed on the portfolio page.

## Downloadable CV

The sidebar Download CV button links to `output/pdf/Thinzar-Hlaing-CV.pdf`. The editable print layout is `output/pdf/Thinzar-Hlaing-CV.html`. After changing CV content, open that file in a browser and print to PDF using A4, no margins, and no browser headers or footers. Replace the PDF at the same path so the download link stays valid.
